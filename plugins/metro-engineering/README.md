# metro-engineering

Design and architecture skills for the volunteer engineering team.

```
/plugin install metro-engineering@metrophilly
```

| Skill | Invoke |
| --- | --- |
| Stress-test a plan or design | `/metro-engineering:grill-me` |
| Extract a DDD glossary | `/metro-engineering:ubiquitous-language` |
| Find refactor / deepening opportunities | `/metro-engineering:improve-codebase-architecture` |
| Hi-fi wireframes for metrophilly.org in the real design system | `/metro-engineering:metro-page-wireframe` |
| Audit from raw data with named methods and outside validation | `/metro-engineering:expert-audit` |

## Known gap

`improve-codebase-architecture/SKILL.md` links to `LANGUAGE.md`,
`DEEPENING.md`, `INTERFACE-DESIGN.md`, and `HTML-REPORT.md`. Those files are
stubs — the originals weren't in the source skill folder. The skill will load
and run, but its glossary and report sections will be thin until the real
content is pasted in.
